# Requirements

> **维护规则**：本文件是**项目整体需求**，仅在**人工明确要求**时修改。AI 不得擅自更新。

---

## 1. 项目定位

**[v0.1 新增] R-v0.1-ck-1**：在现有 Python 加密货币量化交易核心（`dex/` 包，含 10 个策略、ATLAS/GEPA 进化引擎、Binance/OKX/Nado DEX 实盘）之上，新增 Web 后端 + 前端，让策略管理、回测、实盘监控、参数调优具备可视化界面。v0.1 定位为**单机本地使用的个人量化工作台**。

## 2. 目标用户

**[v0.1 新增] R-v0.1-ck-2**：项目作者本人——独立开发者 / 量化爱好者。需要在桌面浏览器里一站式管理策略、跑回测、监控实盘、调优参数，避免频繁切命令行与编辑器。

## 3. 核心功能

**[v0.1 新增] R-v0.1-ck-3** · **策略管理（只读）**：列出 `dex/strategies/` 下 10 个内置策略的类名、参数定义、说明；查看每个策略当前是否有实盘进程在跑、最近一次回测结果摘要。

**[v0.1 新增] R-v0.1-ck-4** · **回测可视化**：自动扫描 `data/crypto/` 下的 parquet 文件作为可选交易对；用户选策略 + 参数（用策略默认参数，v0.1 不支持前端改参数）+ 时间段，调 `BaseStrategy.simulate` 跑回测；前端展示收益曲线、交易明细列表、Sharpe、最大回撤、胜率等核心指标。

**[v0.1 新增] R-v0.1-ck-5** · **实盘监控面板**：支持 Binance / OKX / Nado DEX 三个交易所；后端拉起 `live_binance_quant.py` / `live_okx_quant.py` / `live_nado_quant.py` 子进程；前端展示持仓、未实现盈亏、最近成交、策略状态、实时日志；支持启停。

**[v0.1 新增] R-v0.1-ck-6** · **参数调优 / 进化**：前端触发 ATLAS（`dex/evolution.py`）或 GEPA（`dex/reflection.py`）进化引擎；后端通过 WebSocket 实时推送每代得分、当前最佳参数、进度百分比；结束后展示最终结果与进化曲线。

## 4. 非功能需求

**[v0.1 新增] R-v0.1-ck-7**：
- **性能**：回测在现有 ETH/USDT 5m 数据上 30s 内出结果；WebSocket 进度推送延迟 < 1s；前端首屏加载 < 3s
- **合规**：单机本地使用，不涉及外部用户数据；交易所 API Key 仅存本地 `.env`，不进数据库
- **安全**：无鉴权（单机）；API Key 不通过 HTTP 接口返回前端
- **多端**：v0.1 仅适配桌面浏览器（≥ 1280px 宽），不做 H5 / 移动端
- **可启动性**：一条命令拉起前后端（`uv run python backend/main.py` + `pnpm dev` 或统一脚本）

## 5. 非目标（明确不做什么）

**[v0.1 新增] R-v0.1-ck-8**：
- 多用户 / 鉴权 / 权限隔离
- SaaS 化 / 计费
- 策略参数前端编辑（v0.1 只读，编辑留给 v0.2）
- 新增策略类型（只用现有 10 个）
- 自定义数据上传（只读 `data/crypto/` 本地数据）
- 移动端 / H5 适配
- 历史回测结果持久化（v0.1 仅在内存 / 临时文件，关闭即丢）

## 6. 成功标准

**[v0.1 新增] R-v0.1-ck-9**：
- 本地一条命令启动前后端，浏览器打开能跑通 4 个模块的主流程
- 实盘能从面板启停，日志 / 持仓实时刷新
- 回测能在 30s 内出结果（用现有 ETH/USDT 5m 数据）
- 进化任务能 WebSocket 推送至少 3 代进度，结束后能看最终结果
