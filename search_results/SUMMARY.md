## 冠军: HybridMM (RSI 均值回归 + EMA 动量)

### 参数

```python
rsi_period=7      # 超短RSI，快速捕捉超卖恢复
rsi_low=30        # RSI<30 视为超卖
rsi_high=75       # RSI>75 视为超买
ma_period=30      # 2.5小时EMA趋势确认
atr_period=14     # ATR周期
atr_multiplier=2.5 # 宽止损
max_hold_bars=36  # 最长3小时持仓
```

### 核心逻辑

```
做多: RSI 从 <30 回升到 >=30  AND  价格 > EMA30
做空: RSI 从 >75 回落到 <=75  AND  价格 < EMA30
退出: ATR追踪止损 / EMA反转 / 3小时超时
```

## 为什么 HybridMM 胜出

1. **RSI 交叉过滤**: 等 RSI 从超卖"回升"才入场，而非 PureAction 的价格触碰布林带。在持续下跌中，布林下轨频繁被击穿（假信号），但 RSI 交叉要求卖压先耗尽。

2. **EMA 方向确认**: 93% 的入场满足 price > EMA30，确认至少有短期反弹动能。PureAction 只有 45%。

3. **充足持仓时间**: 最长 3 小时（36 根 × 5min），给利润时间发育。PureAction 最长 1 小时，利润来不及发育就被迫退出。

4. **简单 = 鲁棒**: 不用 ADX（避免 Adaptive 的锁死问题），不用布林带（避免熊市中反复抄底），不用多因子共振（避免过度过滤）。两个核心条件 — RSI 交叉 + EMA 方向 — 足够分离信号和噪音。

## 失败的尝试

| 尝试 | 结果 | 原因 |
|------|------|------|
| PureAction V2 (trend_aligned_only) | 更差 (-28.6%) | 硬闸门导致过度交易 |
| Adaptive (ADX 判市) | 全程空仓 (0 信号) | 趋势模式 RSI 闸门锁死 |
| Multi-TF resample | 灾难 (-95.6%) | HTF 映射引入未来信息泄露 |
| 放宽评分阈值 | 找到"更好"但虚假的参数 | 过拟合 |

## 发现的规律

1. **单边市中，均值回归策略的做多端被系统性压制**。所有策略的做多 PnL 均为负。
2. **合约费率结构利好低频策略**。HybridMM 89 笔交易 vs Scalp 1490 笔 — 后者返佣也补不回亏损。
3. **ADX 判市在 -42% 暴跌中适得其反**。ADX 几乎总是 >25，策略永远锁在"趋势模式"而失去了均值回归的灵活性。
4. **EMA 多周期嵌套是有效的多时间框架**。EMA(close, 288) ≈ 日线趋势，EMA(close, 12) ≈ 1h 趋势 — 不需要 resample。
5. **5分钟级别的策略在极端行情中会失效** — 180 天数据训练的结论在 60 天反弹市中完全不同（HybridMM 在 60 天做到了 +15.46%）。
